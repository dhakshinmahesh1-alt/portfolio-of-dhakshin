# Xio.verce.app — Portfolio

My personal portfolio website built with React, Vite, and Tailwind CSS.

**Live:** [xio.verce.app](https://xio.verce.app)

## Tech Stack

- **Framework:** React 19 + Vite 7
- **Styling:** Tailwind CSS 4
- **Deployment:** Vercel

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
